# 🌟 SalonZen — Luxury Salon Booking Web Application

**SalonZen** is a modern, full-stack luxury salon booking web application designed to deliver a seamless appointment booking experience. Built with cutting-edge web technologies, it features a stunning dark theme with golden-amber accents, role-based dashboards, and secure authentication.

---

## 🚀 Tech Stack & Features

* **Frontend:** Next.js (App Router), React, TypeScript, Tailwind CSS, Shadcn UI
* **Icons & UI Elements:** Lucide React, Radix UI
* **Authentication:** Secure Auth (with MongoDB adapter integration)
* **Styling & Design:** Premium dark mode aesthetic with custom golden-amber highlights and responsive sticky navigation.

---

## ✨ Key Features

* 🔐 **Secure Authentication:** User sign-in, sign-up, and secure session management.
* 👥 **Role-Based Access Control:** Dedicated panels and views for Customers and Administrators.
* 📅 **Service Browsing & Booking:** Explore premium salon services and manage appointments effortlessly.
* 📱 **Fully Responsive:** Optimized for mobile, tablet, and desktop viewports.
* ⚡ **Server-Side Rendering (SSR):** Powered by Next.js for lightning-fast performance and SEO optimization.
